# Ashen Trail — Native C++ Platformer

This folder introduces an original 2D action-platformer built with C++17 and raylib.

## Project package
The complete source, Android project, CMake files, documentation, and original assets are packed in [ashen-trail-native-source.zip](../ashen-trail-native-source.zip).

Extract the archive to use the standalone project folder. Start with its README.md for desktop and Android build instructions.

## Build automation
The repository-level workflow **Ashen Trail native build** extracts the archive, validates assets, builds the desktop target, and attempts an Android arm64 debug APK build. Check the Actions tab for actual build results.

This is a separate project package; existing Game-2D files are not replaced.
